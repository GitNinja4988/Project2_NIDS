EAS 510 · Fall 2026 · Project 2 milestone

How much does NIDS evaluation overestimate performance?

Papers on ML intrusion detection often report 99%+ on CIC-IDS2017 under a random train/test split. This milestone measures how far those scores fall when the test is closer to real use: a Friday time hold-out on CIC-IDS2017, and the authors’ official split on UNSW-NB15.
